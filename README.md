วางป้อม
คลิกป้อมในร้านค้า (ต้องมีเหรียญพอ) จะมีวงกลมรัศมียิงตามเมาส์ สีเขียวคือวางได้ สีแดงคือวางไม่ได้ (ทับถนนหรือทับป้อมอื่น)
คลิกบนแมปที่ต้องการ แล้วจะมีคำถามขึ้นมา เกมหยุดชั่วคราวระหว่างตอบ
คลิกตอบได้เลย ไม่ต้องกดยืนยัน
ตอบถูก: สร้างป้อมทันที และได้โบนัส +25 🪙
ตอบผิด: ข้อที่ถูกไฮไลต์เขียว ข้อที่เลือกไฮไลต์แดง พร้อมคำอธิบายเฉลย ไม่เสียเงินและไม่ได้ป้อม
ยกเลิกการวางได้ด้วยคลิกขวา หรือกด Esc
อัปเกรดและขาย

คลิกป้อมที่วางไว้ จะขึ้นหน้าต่างจัดการ

มี 3 เส้นทางอัปเกรด เส้นละ 5 ขั้น: เส้น 1 เพิ่มดาเมจ เส้น 2 ยิงเร็วขึ้น เส้น 3 เพิ่มระยะและพลังพิเศษของป้อมนั้น
กฎเหมือน BTD6: ขึ้นเส้นทางหลักได้ถึงขั้น 5 เส้นรองได้ไม่เกินขั้น 2 และเส้นที่ 3 ล็อก (เช่น 5-2-0)
ทุกการอัปเกรดต้องตอบคำถามก่อน เหมือนตอนสร้างป้อม
ปุ่มสีแดง "ขายป้อม" คืนเงิน 70% ของเงินที่ลงไปกับป้อมนั้น
ป้อมทุกตัวล็อกเป้าแบบ FIRST คือยิง Bug ที่เดินไปไกลที่สุดในรัศมี

ศัตรู
Syntax Bug: มี 7 ชั้นสี แดง → น้ำเงิน → เขียว → เหลือง → ชมพู → ดำ → ม่วงรุ้ง โดนยิงแล้วจะลอกชั้นบนออกทีละชั้น ชั้นสูงวิ่งเร็วกว่า ถ้าหลุดถึง Base จะหักเลือดเท่าจำนวนชั้นที่เหลือ
Layout Shift: ขยับหลบเป็นจังหวะ ทำให้เดินวูบเร็วเป็นช่วง ๆ
404 Not Found: บอสเลือดเยอะ เดินช้า
M.O.A.B. (ตั้งแต่รอบ 12): แตกเป็น Syntax Bug ชั้นม่วงรุ้ง 4 ตัวเมื่อถูกทำลาย
BFB (ตั้งแต่รอบ 28): แตกเป็น M.O.A.B. 2 ตัว
ZOMG (ตั้งแต่รอบ 45 จึงมีเฉพาะระดับปานกลางและยาก): แตกเป็น BFB 2 ตัว ถ้าหลุดไปถึง Base ตัวเดียวเกมจบทันที
