# 🛡️ Code Defender: HTML, CSS & PHP TD

**Code Defender** คือเกมแนว **Tower Defense** สไตล์ *Bloons TD 6 (BTD6)* ที่ออกแบบมาเพื่อเป็นสื่อการเรียนรู้เชิงรุก (Active Learning) ช่วยทบทวนทักษะการเขียนโปรแกรม **HTML (ม.1), CSS (ม.2) และ PHP (ม.3)** ผ่านระบบการเล่นที่สนุกสนานและท้าทาย

---

## 🎯 เป้าหมายของเกม
ป้องกันเซิร์ฟเวอร์ (**Server Base**) ที่อยู่ด้านล่างของแผนที่จากการบุกรุกของเหล่า **Bug** ที่เดินตามถนน
* **เลือดเซิร์ฟเวอร์ (❤️):** เริ่มต้นที่ 100 หากลดเหลือ 0 จะ **Game Over**
* **เงื่อนไขการชนะ:** ป้องกันเซิร์ฟเวอร์ให้รอดพ้นครบทุกรอบ (Rounds) ตามระดับความยากที่เลือก

---

## 🕹️ เริ่มต้นการเล่น

### 1. เลือกระดับความยาก
| ระดับความยาก | จำนวนรอบ (Rounds) | เหรียญเริ่มต้น (🪙) | ความอึดของ Bug | หมายเหตุ |
| :--- | :---: | :---: | :---: | :--- |

| 🟡 **ปานกลาง (Medium)** | 60 | 400 | 100% | มี Bug ระดับ ZOMG |

## 🖥️ หน้าจอหลักและส่วนประกอบ (HUD)

* **แถบข้อมูลบน:** 
  * 🔴 **ซ้ายบน:** เลือดเซิร์ฟเวอร์ (❤️)
  * 🟡 **ตรงกลาง:** จำนวนเหรียญ (🪙)
  * 🔵 **ขวาบน:** จำนวนรอบปัจจุบัน / รอบทั้งหมด
* **ปุ่มคู่มือ (📖):** คลิกเพื่อเปิดสรุปไวยากรณ์โค้ด HTML, CSS และ PHP ใช้ค้นคว้าทบทวนได้ตลอดเวลา
* **ปุ่มปล่อย Bug (▶️):** ปุ่มสีเขียวสำหรับเริ่มปล่อย Bug ในแต่ละรอบ 
  * *Bug จะไม่เดินออกมาจนกว่าจะกดปุ่มนี้*
  * เมื่อรอบเริ่มแล้ว ปุ่มจะกลายเป็น **ปุ่มสลับความเร็ว (x1 / x2)**
* **แผงร้านค้า (ด้านขวา):** แบ่งป้อมออกเป็น 4 หมวดหมู่ ได้แก่ Primary, Military, Magic และ Support

---

## 🛠️ ระบบการวางป้อมและการตอบคำถาม

1. **เลือกป้อม:** คลิกป้อมที่ต้องการในร้านค้า (เมื่อมีเหรียญพอ)
2. **เลือกตำแหน่ง:** ลากป้อมไปยังพื้นที่บนแมป
   * 🟢 **วงกลมสีเขียว:** วางได้
   * 🔴 **วงกลมสีแดง:** วางไม่ได้ (ทับถนน หรือทับป้อมอื่น)
3. **ตอบคำถามเพื่อสร้าง:** เมื่อคลิกวาง จะมีหน้าต่างคำถามขึ้นมา (เกมจะหยุดชั่วคราว)
   * **คลิกเลือกคำตอบทันที** (ไม่ต้องกดกดยืนยัน):
     * ✅ **ตอบถูก:** สร้างป้อมสำเร็จ พร้อมรับโบนัสทันที **+25 🪙**
     * ❌ **ตอบผิด:** แสดงเฉลยทันที (ไฮไลต์เขียวข้อถูก / ไฮไลต์แดงข้อผิด) **ไม่เสียเงิน และไม่ได้ป้อม**
4. **การยกเลิก:** คลิกขวา หรือกดปุ่ม `Esc` เพื่อยกเลิกการวางป้อม

## ⬆️ ระบบอัปเกรดและขายป้อม

คลิกที่ป้อมที่วางอยู่บนแมปเพื่อเปิดหน้าต่างจัดการ:

* **เส้นทางอัปเกรด (Upgrade Paths):** มี 3 เส้นทาง เส้นทางละ 5 ขั้น
  * **Path 1:** เพิ่มดาเมจ (Damage)
  * **Path 2:** เพิ่มความเร็วการยิง (Attack Speed)
  * **Path 3:** เพิ่มระยะการยิง และพลังพิเศษเฉพาะตัว (Range & Abilities)
* **กฎการอัปเกรด (BTD6 Rules):** 
  * สามารถอัปเกรดสายหลักได้สูงสุดถึง **ขั้น 5**
  * สายรองได้ไม่เกิน **ขั้น 2**
  * สายที่เหลือจะถูก **ล็อก (0)** *(เช่น รูปแบบ 5-2-0)*
* **การตอบคำถาม:** ทุกการอัปเกรดจะต้องตอบคำถามภาษาให้ถูกต้องก่อน
* **การขายป้อม (Sell):** กดปุ่มขายสีแดงเพื่อรับเงินคืน **70%** ของจำนวนเงินทั้งหมดที่ลงทุนไป
* **ระบบล็อกเป้าหมาย (Targeting):** ป้อมทุกตัวล็อกเป้าหมายแบบ **FIRST** (ยิง Bug ตัวที่เดินไปได้ไกลที่สุดในรัศมีก่อนเสมอ)

## 🏹 ป้อมทั้ง 11 ชนิด (Towers)

คำถามของป้อมจะถูกแบ่งตามระดับชั้น ดังนี้:
* 🟢 **ม.1 (HTML):** HTML, Regex Ninja, API Bank
* 🔵 **ม.2 (CSS):** CSS, Grid Tack, JS Wizard, Dev Community
* 🟣 **ม.3 (PHP):** PHP, SQL Sniper, Loop Gatling, Quantum CPU

### 1. หมวด Primary
* **HTML** `(100 🪙)` — ยิงเป้าหมายเดี่ยวรวดเร็ว
* **CSS** `(150 🪙)` — ปล่อยคลื่นแช่แข็ง ชะลอความเร็ว Bug 50% เป็นเวลา 2 วินาที
* **Grid Tack** `(180 🪙)` — สร้างคลื่นดาเมจรอบตัวระยะสั้น

### 2. หมวด Military
* **PHP** `(250 🪙)` — ยิงระเบิดเป็นวง เหมาะกับ Bug ที่มีเกราะ/เลือดเยอะ
* **SQL Sniper** `(300 🪙)` — ยิงไกลครอบคลุมทั่วทั้งแมป ดาเมจสูง
* **Loop Gatling** `(350 🪙)` — ความเร็วการยิงสูงมาก เหมาะกับฝูง Bug หลายชั้น

### 3. หมวด Magic
* **JS Wizard** `(275 🪙)` — ยิงสายฟ้ากระโดดข้ามใส่หลายเป้าหมาย
* **Regex Ninja** `(325 🪙)` — โจมตี 2 เป้าหมายพร้อมกันอย่างแม่นยำ
* **Quantum CPU** `(2,000 🪙)` — ป้อมปลายเกม ยิงรวดเร็วและทรงพลังสูงสุด

### 4. หมวด Support
* **API Bank** `(400 🪙)` — ไม่โจมตี แต่สร้างรายได้พิเศษให้ทุกจบรอบ
* **Dev Community** `(500 🪙)` — ปล่อยบัฟให้ป้อมรอบข้างยิงได้เร็วขึ้นและไกลขึ้น

## 👾 ศัตรู (Bugs)

* **Syntax Bug:** มี 7 ชั้นสีตามลำดับความแข็งแกร่ง:  
  🔴 แดง ➡️ 🔵 น้ำเงิน ➡️ 🟢 เขียว ➡️ 🟡 เหลือง ➡️ 🌸 ชมพู ➡️ ⬛ ดำ ➡️ 🌈 ม่วงรุ้ง
  * การโดนยิงจะลอกชั้นสีออกทีละชั้น
  * ชั้นยิ่งสูงยิ่งเคลื่อนที่เร็ว
  * หากหลุดเข้า Base จะหักเลือดเท่ากับจำนวนชั้นที่เหลือ
* **Layout Shift:** เคลื่อนที่ขยับหลบเป็นจังหวะ ทำให้พุ่งเร็วเป็นช่วงๆ
* **404 Not Found:** บอสเลือดเยอะ เคลื่อนที่ช้า
* **M.O.A.B. (ปรากฏตั้งแต่รอบ 12):** เมื่อถูกทำลาย จะแตกออกเป็น *Syntax Bug ชั้นม่วงรุ้ง 4 ตัว*
* **BFB (ปรากฏตั้งแต่รอบ 28):** เมื่อถูกทำลาย จะแตกออกเป็น *M.O.A.B. 2 ตัว*
* **ZOMG (ปรากฏตั้งแต่รอบ 45 - เฉพาะระดับปานกลางและยาก):** บอสระดับเรือประจัญบาน เมื่อถูกทำลาย จะแตกออกเป็น *BFB 2 ตัว* *(หากหลุดเข้า Base ตัวเดียวเกมจบ即ที!)*

## 💰 ระบบการรับเหรียญ (Gold)

1. **ทำลาย Bug:** ได้รับเหรียญเมื่อทำลาย Bug และได้ **+1 🪙** ทุกครั้งที่ลอกชั้นสีของ Bug
2. **โบนัสตอบคำถาม:** ตอบคำถามถูกต้อง ได้รับ **+25 🪙**
3. **โบนัสจบรอบ:** ได้รับโบนัสตามสูตร `60 + (10 × เลขรอบปัจจุบัน)`
4. **รายได้เสริม:** ได้รับเงินปันผลเพิ่มเติมจากป้อม **API Bank** ในทุกๆ จบรอบ

## 💡 เคล็ดลับการเล่น (Tips & Strategies)

1. **การวางจุดเริ่มต้น:** ในช่วงต้นเกม ควรวาง **HTML** บริเวณทางโค้ง เพื่อให้รัศมีการยิงครอบคลุมถนนได้หลายช่วงที่สุด
2. **คอมโบชะลอความเร็ว:** จับคู่ป้อม **CSS (Slow)** ไว้คู่กับป้อมสร้างดาเมจสูง เช่น **PHP** หรือ **Loop Gatling** จะช่วยจัดการ Bug ได้มีประสิทธิภาพมากขึ้น
3. **วางแผนการเงิน:** สร้าง **API Bank** ตั้งแต่เนิ่นๆ เพื่อสะสมดอกเบี้ยระยะยาว และสร้าง **Dev Community** ไว้กลางกลุ่มป้อมหลักเพื่อเพิ่มสเตตัสแบบกลุ่ม
4. **รับมือเรือรบขนาดใหญ่:** เมื่อต้องเจอ **M.O.A.B. / BFB / ZOMG** ให้เน้นใช้ **PHP** และ **SQL Sniper** ทำลายเกราะนอก ส่วนฝูง Bug ชั้นในให้ใช้ **Loop Gatling** เก็บงาน
5. **อย่ากลัวการตอบผิด:** การตอบคำถามผิดไม่เสียเงินและไม่หักคะแนน อ่านเฉลยที่ขึ้นมาแล้วลองใหม่ หรือเปิดดูคู่มือ (📖) เพื่อเรียนรู้ไวยากรณ์ที่ถูกต้องได้ตลอดเวลา
